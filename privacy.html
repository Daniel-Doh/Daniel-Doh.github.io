Privacy policy

Last updated: 2026-11-13

westwing hygiene is a personal tool. Its only user is its owner, and it accesses only the owner's own Gmail account.

What it reads

Message metadata only: sender, subject, date, labels, and the List-Unsubscribe header. It does not read message bodies, except the most recent message from a sender when the unsubscribe link appears only in the body.

Where it goes

The data is stored on the owner's own computer. Per-sender summaries (sender, message counts, dates) may be sent to an AI model API operated on the owner's behalf, only to suggest which senders to keep or unsubscribe from. The data is not sold, shared, or used to train AI models.

Limited Use

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions.
